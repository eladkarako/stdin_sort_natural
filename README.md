<h3><img src="resources/app.png" /> stdin_sort_natural</h3>1. consumes whole initial `STDIN`.2. split by lines.3. trim space and tab characters from start and end of each line.4. remove empty lines.5. sort lines using natural sort (`1<2<10<20`).6. remove duplicated lines. ignoring letter-case.7. joins line using end-of-line sequence suitable for the OS (`\r\n` for Windows, `\n` for linux). no additional end-of-line sequence added to the end of the content.8. outputs it to `STDOUT`.note: this program changes the content.note: Windows pipeline adds `\r\n` at the end of the content. it shouldn't matter in here, as empty lines are being removed, as well as duplicated lines, and no end-of-line sequence is added to the end of the content.<hr/>### build:```cargo cleanrustup target add   x86_64-pc-windows-msvc   i686-pc-windows-msvccargo build  --release  --target   x86_64-pc-windows-msvccargo build  --release  --target   i686-pc-windows-msvcrustup target add   x86_64-linux-android   i686-linux-android   aarch64-linux-android   armv7-linux-androideabicargo build  --release  --target   x86_64-linux-androidcargo build  --release  --target   i686-linux-androidcargo build  --release  --target   aarch64-linux-androidcargo build  --release  --target   armv7-linux-androideabirustup target add   x86_64-unknown-linux-gnu   aarch64-unknown-linux-gnu   x86_64-unknown-linux-musl   aarch64-unknown-linux-muslcargo build  --release  --target   x86_64-unknown-linux-gnucargo build  --release  --target   aarch64-unknown-linux-gnucargo build  --release  --target   x86_64-unknown-linux-muslcargo build  --release  --target   aarch64-unknown-linux-musl```
